# german-delgado-site

Tema hijo Glitche para el portafolio personal de Germán Delgado.

## Demo

🌐 [germandelgado.site](https://germandelgado.site)

## Stack

- WordPress
- PHP
- CSS personalizado
- Git auto-deploy a Hostinger

## Características

- Modo oscuro forzado.
- Perfil, portafolio, CV y contacto en una sola página.
- Sección de proyectos con tarjetas de logos.
- Despliegue automático desde GitHub a Hostinger.
